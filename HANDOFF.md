## Дизайн-система
- Цвета: чёрный/графит `--black: #474b4e` (RAL 7024), красный `--red: #cc0605` (RAL 3020), плюс `--black-soft`, `--off-white`, `--gray`.
- Шрифты: заголовки — Oswald, текст — Manrope (Google Fonts).
- Хедер — фиксированный сверху (НЕ сайдбар), с логотипом, меню, кнопкой «Связаться», на мобиле — бургер-меню.
- Стиль карточек: `.dev-family`, `.model-card`, `.sub-block` + `.sub-grid` (фото/текст попеременно) — используется по всему сайту, единообразно.

## Структура страницы (одностраничник, секции по порядку)
1. **Hero** (`#top`) — полноэкранное видео (плещущаяся вода, `assets/waves.mp4`), заголовок, подзаголовок, кнопки, бейджи «ОЭЗ Дубна» и «АНО Судпром», статистика. Эйбрау «Сделано в России» — яркая красная плашка.
2. **О компании** (`#about`) — история/миссия + 3 преимущества (в `.about-grid`), затем подряд: «Концепция» (список + инфографика), «Команда и компетенции» (схема КБ: МГТУ Баумана объединённый узел + НАМИ + АвтоВАЗ + Самарский университет). Раздел «Предпосылки» — **удалён** по просьбе пользователя.
3. **Партнёры** (`#partners`) — тёмная секция, сетка карточек: МГТУ Баумана, ФГУП НАМИ, АВТОТОР, Нацассоциация маломерного судоходства.
4. **Модели** (`#models`) — флагман **«ПАТРИОТ 60–80»** (объединили бывший отдельный «ПАТРИОТ 80» + семейство 60-80: полные технические характеристики, 8 клапанов, фото, CAD-рендеры). Текст про «суда 5–6 м» под флагманом — **удалён** по просьбе пользователя.
   Заголовок **«В разработке»** — крупный, чёрный, с красной полосой слева (по просьбе — «сильно заметно»). Далее подряд карточки: 80–150 л.с. (16 клапанов, дорожная карта с датой **дек 2028**), 40–60 л.с., 250–600 л.с. (текст «экспортный потенциал» выделен красным), Алюминиевый блок цилиндров, Производство кормового привода.
5. **Производство** (`#production`) — фото завода, текст (площадь сборочного цеха — **1500 м²**, изменено с 2000), статистика, адрес.
6. **Пресса** — бегущая строка с упоминаниями в СМИ.
7. **Контакты** (`#contacts`) — две карточки с картой (`.location-cards`): **Москва** (офис, ул. Авиамоторная 34к1, встроенная карта OpenStreetMap) и **Дубна** (производство, тоже с картой). Координаты уточнены через геокодер (Nominatim), метки стоят правильно. Далее — блок «Сайт» + форма обратной связи. Карточки «Генеральный директор» / «Главный конструктор» — **удалены** по просьбе пользователя.

## Важные решения и правки, которые стоит помнить
- Логотип — **официальный цветной** файл (`assets/logo-official.svg`), найден в `Downloads\Telegram Desktop\Лого_вывеска.svg`. В хедере/футере обёрнут в `.logo-badge` (белая подложка), т.к. логотип цветной, а не белый — иначе серый текст логотипа сливается с тёмным фоном.
- Реальные контактные данные (директор/конструктор, адреса, характеристики моторов) взяты из презентаций компании (PDF/PPTX), которые пользователь присылал в чат — не выдуманы. Если каких-то данных не хватает — **не придумывать**, спрашивать пользователя или искать в его файлах (Downloads, Telegram Desktop).
- Логотипы партнёров/сертификатов (АНО «Судпром», ТПП РФ) — если нужно добавить ещё — их нет как отдельных файлов, только вставленные в чат картинки; при вставке пользователем файла (например, скриншот) он иногда появляется в `Downloads\` с именем вида `2026-MM-DD_HH-MM-SS.png` — стоит проверять там при следующих похожих просьбах.
- Есть также **второй вариант сайта** — `npp-patriot-site-v2` (папка рядом), с другой версией структуры (двухстраничный: `index.html` про моторы + `company.html` про компанию). Пользователь попросил сфокусироваться на первом сайте — про v2 сейчас речи нет, но он существует и опубликован на `https://tapochek590.github.io/npp-patriot-site-v2/`.
